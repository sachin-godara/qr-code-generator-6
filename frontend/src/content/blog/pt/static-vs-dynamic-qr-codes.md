## Comparação Direta

| Recurso | QR Code Estático | QR Code Dinâmico |
| :--- | :--- | :--- |
| **Armazenamento dos dados** | Gravado diretamente na imagem | Salvo através de link curto de redirecionamento |
| **Editável após impressão** | ❌ Não | ✅ Sim |
| **Estatísticas e rastreamento** | ❌ Não | ✅ Sim |
| **Validade** | **Nunca expira** | Pode expirar (depende do plano) |
| **Dependência de servidores** | Nenhuma (funciona offline) | Exige que o servidor da empresa esteja ativo |
| **Privacidade** | Máxima (sem rastreamento) | Os acessos são gravados em servidores terceiros |
| **Custo** | **100% Gratuito** | Geralmente requer assinatura mensal |
| **Ideal para** | Cartões de visita, cardápios, rótulos e embalagens | Campanhas de marketing temporárias, testes A/B |

## O que é um QR Code Estático?

Um código QR estático armazena os dados (como uma URL de site, texto ou cartão vCard) **diretamente nos pixels do padrão visual**. Uma vez criado, o conteúdo é permanente.

### Vantagens do QR Code Estático
- **Permanente e Eterno**: Não expira nunca.
- **Independência Total**: Mesmo que o site gerador encerre as atividades, seu QR code continua funcionando perfeitamente.
- **Privacidade Absoluta**: Não rastreia os usuários nem grava histórico de acessos.
- **Sem Custos Ocultos**: Totalmente gratuito, sem taxas de manutenção.

### Desvantagens
- **Conteúdo Fixo**: Se a URL mudar, é necessário imprimir um novo material.
- **Sem Métricas**: Não é possível contabilizar quantos scans foram feitos.

---

## O que é um QR Code Dinâmico?

O QR code dinâmico codifica uma **URL curta de redirecionamento** controlada por uma plataforma comercial de QR codes.

### Vantagens
- **URL Editável**: Permite alterar o site de destino sem precisar reimprimir cartazes ou embalagens.
- **Métricas Detalhadas**: Exibe relatórios de quantidade de leituras, tipos de smartphone e horários.

### Desvantagens
- **Risco de Cancelamento**: Se a assinatura não for renovada, todos os códigos impressos param de funcionar imediatamente.
- **Menos Privacidade**: Os dados de navegação de quem escaneia são coletados pelo fornecedor.

---

## Qual Tipo Você Deve Escolher?

### Escolha o QR Code Estático se:
- O link de destino for definitivo (site oficial, WhatsApp, Wi-Fi, cartão de visita).
- Você busca uma solução gratuita e sem mensalidades.
- A privacidade e a garantia de funcionamento a longo prazo forem fundamentais.

### Escolha o QR Code Dinâmico se:
- Você realiza promoções semanais que mudam de página com frequência.
- Você precisa apresentar relatórios de ROI com contagem de cliques.
