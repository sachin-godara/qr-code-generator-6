Every hotel guest and Airbnb visitor asks the same question: *"What's the WiFi password?"* A WiFi QR code eliminates this friction entirely — guests scan once and connect instantly.

## Why Hotels & Airbnb Need WiFi QR Codes

### The Problem
- Guests repeatedly ask staff for WiFi credentials
- Complex passwords are hard to type (especially `xK9#mLp$2qR`)
- Paper slips get lost or damaged
- Password changes require reprinting all materials

### The Solution
A WiFi QR code encodes your network name (SSID), password, and encryption type directly. When a guest scans it, their phone **automatically connects** — no typing required.

## Security Best Practices

### Use a Dedicated Guest Network

**Never share your main network** with guests. Set up a separate guest network on your router that:
- Isolates guests from your private devices
- Limits bandwidth per user
- Can have its password changed without affecting your devices

### Rotate Passwords Regularly

For hotels, change guest WiFi passwords monthly or quarterly. For Airbnb, consider changing between each guest. When you change the password:
1. Generate a new WiFi QR code
2. Replace the printed copies
3. Update the listing description

### WPA2 vs WPA3

| Encryption | Security Level | Compatibility |
|-----------|---------------|--------------|
| **WPA2** | Good | Works with all devices (recommended) |
| **WPA3** | Best | Newer devices only (may exclude some guests) |
| **WEP** | ❌ Insecure | Never use — easily hackable |
| **None** | ❌ Open | Never use for a network with personal devices |

For guest networks, **WPA2** offers the best balance of security and compatibility.

## Troubleshooting WiFi QR Codes

| Issue | Solution |
|-------|---------|
| QR code doesn't connect | Double-check SSID spelling (case-sensitive) |
| Works on iPhone but not Android | Some older Android versions require a dedicated scanner app |
| "Authentication failed" | Password is case-sensitive — verify exact characters |
| Hidden network not found | Ensure "Hidden" toggle is ON in the QR generator |
| 5GHz network not connecting | Some devices only see 2.4GHz — use the 2.4GHz SSID instead |
