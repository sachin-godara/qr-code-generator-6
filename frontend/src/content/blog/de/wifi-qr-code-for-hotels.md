Jeder Hotelgast und Airbnb-Besucher stellt dieselbe Frage: *"Wie lautet das WLAN-Passwort?"* Ein WLAN-QR-Code beseitigt diese Hürde vollständig — Gäste scannen den Code einmal und verbinden sich augenblicklich.

## Warum Hotels & Airbnb WLAN-QR-Codes benötigen

### Das Problem
- Gäste fragen das Personal wiederholt nach den Zugangsdaten
- Komplexe Passwörter sind mühsam einzutippen (besonders Zeichenfolgen wie `xK9#mLp$2qR`)
- Zettel mit Passwörtern gehen verloren oder nutzen sich ab
- Passwortänderungen erfordern den Neudruck aller Informationsmaterialien

### Die Lösung
Ein WLAN-QR-Code codiert Ihren Netzwerknamen (SSID), das Passwort und den Verschlüsselungstyp direkt im Bild. Wenn ein Gast den Code scannt, verbindet sich sein Smartphone **automatisch** — ganz ohne Tippen.

## So erstellen Sie einen WLAN-QR-Code

1. Öffnen Sie den [GenerateCustomQR WLAN-Generator](/de/wifi-qr-code).
2. Geben Sie Ihren **Netzwerknamen (SSID)** ein — exakt so, wie er in den WLAN-Einstellungen angezeigt wird.
3. Geben Sie Ihr **Passwort** ein.
4. Wählen Sie Ihren **Verschlüsselungstyp** (WPA/WPA2 für die meisten Router).
5. Aktivieren Sie "Verstecktes Netzwerk", falls Ihre SSID nicht öffentlich ausgestrahlt wird.
6. Passen Sie das Design an Ihre Marke an.
7. Laden Sie die Datei herunter und drucken Sie sie aus.

## Design-Tipps für WLAN-Codes im Gastgewerbe

### Passend zu Ihrer Marke

Nutzen Sie das Farbschema Ihres Hotels oder Gästehauses:
- **Luxushotels**: Dunkles Marineblau, Gold-Akzente, elegante Punktstile
- **Boutique-Hotels**: Eigene Markenfarben mit zentriertem Logo
- **Airbnb-Unterkünfte**: Warme, einladende Farben; gemütliches Design
- **Cafés**: Erdige Töne kombiniert mit dem Café-Logo

### Klare Handlungsaufforderung hinzufügen

Fügen Sie immer einen kurzen Hinweis über oder unter dem QR-Code hinzu:
- ✅ *"Scannen für WLAN-Verbindung"*
- ✅ *"Kostenloses WLAN — Hier scannen"*
- ✅ *"Gästenetzwerk — Jetzt verbinden"*

Nutzen Sie die **CTA-Textrahmen** von GenerateCustomQR, um diese Beschriftung direkt in das Bild zu integrieren.

### Passwort zusätzlich als Text abdrucken

Einige ältere Geräte können WLAN-QR-Codes nicht nativ scannen. Drucken Sie das Passwort als Ausweichmöglichkeit stets in Textform neben den Code:

```
Netzwerk: HotelGast_5G
Passwort: Willkommen2025!
Oder scannen Sie den QR-Code für Sofortverbindung:
[QR-CODE]
```

## Sicherheits-Best-Practices

### Separates Gastnetzwerk einrichten

**Teilen Sie niemals Ihr Hauptnetzwerk** mit Gästen. Richten Sie auf Ihrem Router ein eigenständiges Gastnetzwerk ein, das:
- Gäste von Ihren privaten Geräten und Kassensystemen isoliert
- Die Bandbreite pro Nutzer bei Bedarf begrenzt
- Dessen Passwort jederzeit geändert werden kann, ohne eigene Geräte neu verbinden zu müssen

### Passwörter regelmäßig wechseln

In Hotels empfiehlt sich ein monatlicher oder quartalsweiser Wechsel des Gastpassworts. Bei Ferienwohnungen kann das Passwort zwischen verschiedenen Gästegruppen erneuert werden:
1. Neuen WLAN-QR-Code generieren
2. Druckvorlagen austauschen
3. Buchungsunterlagen aktualisieren

### WPA2 vs. WPA3

| Verschlüsselung | Sicherheitsstufe | Kompatibilität |
|-----------------|------------------|----------------|
| **WPA2** | Gut | Funktioniert auf allen Geräten (empfohlen) |
| **WPA3** | Höchste | Nur neuere Geräte (kann ältere Handys ausschließen) |
| **WEP** | ❌ Unsicher | Veraltet — leicht angreifbar |
| **Keine** | ❌ Offen | Niemals für Netzwerke mit persönlichen Daten nutzen |

Für Gastnetzwerke bietet **WPA2** das optimale Gleichgewicht aus Schutz und maximaler Gerätekompatibilität.

## Fehlerbehebung bei WLAN-QR-Codes

| Problem | Lösung |
|---------|--------|
| Code verbindet nicht | SSID-Schreibweise prüfen (Groß-/Kleinschreibung beachten) |
| Funktioniert auf iPhone, nicht auf Android | Ältere Android-Versionen benötigen eine separate Scanner-App |
| "Authentifizierung fehlgeschlagen" | Passwort auf exakte Zeichen prüfen |
| Verstecktes Netzwerk wird nicht gefunden | Schalter "Verstecktes Netzwerk" im Generator aktivieren |
| 5GHz-Netz verbindet nicht | Einige Geräte unterstützen nur 2,4 GHz — 2,4-GHz-SSID nutzen |
