Eine der häufigsten Fragen beim Erstellen eines QR-Codes lautet: *"Wie groß muss der Code gedruckt werden?"* Die Antwort hängt vom Einsatzort, dem Scanabstand der Nutzer und der codierten Datenmenge ab.

Dieser Leitfaden liefert präzise Größenempfehlungen für alle gängigen Praxisszenarien.

- **Scan-Abstand 30 cm** (z. B. Visitenkarte in der Hand): Mindestgröße **3 × 3 cm**.
- **Scan-Abstand 3 Meter** (z. B. Wandplakat): Mindestgröße **30 × 30 cm**.
- **Scan-Abstand 10 Meter** (z. B. Werbebanner an einer Fassade): Mindestgröße **100 × 100 cm**.

## Einfluss der Datenmenge auf die Rasterdichte

Je mehr Zeichen codiert werden, desto mehr Module (Punkte) benötigt die QR-Matrix. Ein feineres Raster verlangt größere Maße:

| Inhaltstyp | Modulanzahl | Auswirkung auf Mindestgröße |
| :--- | :--- | :--- |
| **Kurze URL** (< 50 Zeichen) | 25×25 Module | Standardgröße ausreichend |
| **Mittlere URL** (50–100 Zeichen) | 33×33 Module | +10% Vergrößerung |
| **Lange URL** (100–200 Zeichen) | 41×41 Module | +25% Vergrößerung |
| **vCard** (Vollständiger Kontakt) | 45×45 Module | +30% Vergrößerung |
| **WLAN-Zugangsdaten** | 29×29 Module | Standardgröße ausreichend |
| **Freitext** (500+ Zeichen) | 57×57+ Module | +50% oder mehr |

## Fehlerkorrektur und Abmessungen

| Level | Wiederherstellung | Auswirkung | Bester Einsatz |
| :---: | :---: | :---: | :--- |
| **L** (Low) | 7% | Sehr kompakt | Bildschirme, reine URLs ohne Logo |
| **M** (Medium) | 15% | +10% Größe | **Standard** für Flyer und Magazine |
| **Q** (Quartile) | 25% | +20% Größe | Außenbereiche, raue Oberflächen |
| **H** (High) | 30% | +30% Größe | **Pflicht bei Firmenlogos** |

Wenn Sie ein Logo in Ihren QR-Code einbinden, verwenden Sie immer die Fehlerkorrekturstufe **H**. Dadurch wird der Code physisch dichter, weshalb Sie etwa 30% zusätzliche Fläche bei der Größenplanung einrechnen sollten.

## Auflösungsanforderungen nach Exportformat

Die optimale Größe hängt nicht nur von den physischen Zentimetern ab — auch die Pixeldichte muss für den Druck stimmen:

| Exportformat | Empfohlene Auflösung | Bester Einsatzbereich |
| :--- | :--- | :--- |
| **PNG** | 300 DPI für Print, 72 DPI für Web | Universell für digitale Medien und Bildschirme |
| **SVG** | Unendlich (Vektorgrafik) | Verlustfreier Druck in beliebiger Größe ohne Pixel |
| **PDF** | 300 DPI eingebettet | Professionelle Druckereien, Broschüren & Plakate |

## Häufige Fehler bei der Größenwahl

### 1. Zu kleiner Ausdruck
QR-Codes unter 2 cm × 2 cm sind fehleranfällig, besonders bei älteren Kameras oder gedämpftem Umgebungslicht.

### 2. Ruhezone abgeschnitten
Der weiße Rand (Quiet Zone) um den QR-Code muss mindestens 4 Module breit sein. Wird dieser Rand beschnitten, kann die Smartphone-Kamera den Code oft nicht erfassen.

### 3. Zu geringe Bildauflösung im Druck
Ein PNG mit 300×300 Pixeln sieht am Bildschirm scharf aus, wird auf einem DIN-A4-Plakat aber unscharf. Für den Druck immer Vektor-SVG oder 300-DPI-PDF nutzen.
