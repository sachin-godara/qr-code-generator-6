Das Anpassen der QR-Code-Farben an Ihr Corporate Design ist ein wirkungsvolles Branding-Instrument. Nicht jede Farbkombination wird jedoch von Smartphone-Kameras schnell erkannt.

## Die Grundregel: Dunkle Punkte auf hellem Grund

QR-Code-Scanner erfassen **optische Helligkeitsunterschiede**. Die wichtigste Regel lautet:

> **Immer dunkle Datenpunkte auf hellem Hintergrund.**

## Kontraststufen im Überblick

| Kontrastverhältnis | Scan-Ergebnis |
| :--- | :--- |
| **7:1 oder höher** | ✅ Perfekt — scannt unter allen Lichtverhältnissen |
| **4.5:1 bis 7:1** | ✅ Sehr gut — zuverlässig auf allen Standard-Smartphones |
| **3:1 bis 4.5:1** | ⚠️ Kritisch — Scanprobleme bei Dämmerlicht |
| **Unter 3:1** | ❌ Nicht lesbar — hohe Ausfallquote |

## Bewährte Farbkombinationen

### Maximaler Kontrast (7:1+)

| Punktfarbe | Hintergrund | Kontrast | Markenwirkung |
| :--- | :--- | :--- | :--- |
| **Schwarz `#000000`** | Weiß `#FFFFFF` | 21:1 | Klassisch, universell |
| **Marineblau `#1A237E`** | Weiß `#FFFFFF` | 16:1 | Business, Finanzen |
| **Dunkelgrün `#1B5E20`** | Weiß `#FFFFFF` | 11:1 | Nachhaltigkeit, Natur |
| **Bordeauxrot `#880E4F`** | Weiß `#FFFFFF` | 10:1 | Premium, Gastronomie |
| **Anthrazit `#212121`** | Hellgrau `#F5F5F5` | 16:1 | Modern, minimalistisch |
