Wenn Sie nach einem QR-Code-Generator suchen, begegnen Ihnen oft die Begriffe "statisch" und "dynamisch". Doch was bedeuten sie und welche Variante eignet sich für Ihre Zwecke?

In diesem Ratgeber vergleichen wir beide Technologien detailliert.

## Schneller Vergleich

| Merkmal | Statischer QR-Code | Dynamischer QR-Code |
|---|---|---|
| **Datenspeicherung** | Direkt im Bildmuster kodiert | Weiterleitung über Kurz-URL |
| **Nachträglich änderbar** | Nein | Ja |
| **Scan-Statistiken** | Keine (100% Datenschutz) | Ja (Ort, Zeit, Gerät) |
| **Gültigkeit** | Läuft niemals ab | Kann ablaufen (anbieterabhängig) |
| **Server-Abhängigkeit** | Keine — funktioniert auch offline | Server des Anbieters muss online sein |
| **Datenschutz** | Maximal — kein Nutzertracking | Scans werden protokolliert |
| **Kosten** | 100% Kostenlos | Meist monatliches Bezahl-Abo |
| **Bester Einsatz** | Visitenkarten, Drucksachen, Menüs | Marketing-Kampagnen, A/B-Tests |

## Was ist ein statischer QR-Code?

Ein statischer QR-Code speichert die gewünschten Daten **direkt im Punktmuster des Bildes**. Nach der Generierung sind die Daten fest mit der Grafik verschmolzen.

### Wie er funktioniert

Beim Scannen decodiert das Smartphone das Muster und ruft den Inhalt direkt auf. Es gibt keinen Zwischenserver und keine Umleitung.

### Vorteile statischer QR-Codes

- **Läuft niemals ab** — Daten liegen im Bild, funktioniert dauerhaft
- **Keine Serverabhängigkeit** — Funktioniert selbst wenn die Erstellungs-Website offline geht
- **Maximaler Datenschutz** — Keine Speicherung von Nutzerdaten
- **Vollkommen kostenlos** — Keine versteckten Gebühren oder Abos
- **Schnellere Ladezeiten** — Direkter Aufruf ohne Redirect-Verzögerung

### Nachteile statischer QR-Codes

- **Nicht editierbar** — Bei URL-Änderungen muss der Code neu gedruckt werden
- **Keine Statistiken** — Keine Messung der Scan-Häufigkeit
- **Dichtere Muster bei langen Texten** — Lange URLs erzeugen feinere Raster

### Typische Einsatzbereiche

- **Visitenkarten** — Dauerhafte Kontaktdaten
- **Produktverpackungen** — Feste Produkt-Websites
- **Speisekarten** — Dauerhafter Menü-Link
- **WLAN-Zugänge** — Netzwerkdaten teilen
- **Veranstaltungsschilder** — Wegweiser und Aushänge

## Was ist ein dynamischer QR-Code?

Ein dynamischer QR-Code kodiert eine **kurze Weiterleitungs-URL** (z. B. `qr.example.com/xyz`), die auf einem Server des Anbieters liegt und zum eigentlichen Ziel weiterleitet.

### Vorteile dynamischer QR-Codes

- **Nachträglich editierbar** — Ziel-URL ohne Neudruck austauschen
- **Ausführliche Statistiken** — Scans nach Ort, Zeit und Gerätetyp messen
- **Kürzere URLs** — Erzeugt weniger dichte QR-Raster
- **A/B-Tests** — Traffic auf verschiedene Seiten aufteilen

### Nachteile dynamischer QR-Codes

- **Server-Abhängigkeit** — Geht der Anbieter pleite, wird der Code unbrauchbar
- **Kostenpflichtig** — Meist monatliche Gebühren
- **Datenschutzbedenken** — Jeder Scan wird getrackt
- **Ablaufgefahr** — Kostenlose Test-Codes werden oft nach 14–30 Tagen deaktiviert

## Welchen Typ sollten Sie wählen?

**Wählen Sie Statisch, wenn:**
- Ihre Web-Adresse dauerhaft stabil bleibt
- Sie keine Scan-Analysen benötigen
- Sie keine laufenden monatlichen Kosten möchten
- Datenschutz Ihnen oder Ihren Kunden wichtig ist
- Sie Visitenkarten, Verpackungen oder Speisekarten drucken

**Wählen Sie Dynamisch, wenn:**
- Sie die Ziel-URL nach dem Druck austauschen müssen
- Sie Werbekampagnen mit Klickraten auswerten wollen
- Sie bereit sind, ein monatliches Software-Abo zu bezahlen
