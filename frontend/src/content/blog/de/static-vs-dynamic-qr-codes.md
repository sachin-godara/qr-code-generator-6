Wer nach einem QR-Code-Generator sucht, stößt unweigerlich auf die Begriffe „statisch“ und „dynamisch“. Doch was bedeuten sie in der Praxis und welche Variante ist die richtige für Ihr Vorhaben?

In diesem Leitfaden stellen wir die Vor- und Nachteile beider Systeme gegenüber.

---

## Direkter Vergleich

| Eigenschaft | Statischer QR-Code | Dynamischer QR-Code |
| :--- | :--- | :--- |
| **Datenspeicherung** | Fest im Bildmuster codiert | Gespeichert als Weiterleitungs-URL |
| **Nachträglich änderbar** | ❌ Nein | ✅ Ja |
| **Scan-Statistiken / Tracking** | ❌ Nein | ✅ Ja |
| **Gültigkeitsdauer** | **Läuft niemals ab** | Kann ablaufen (anbieterabhängig) |
| **Server-Abhängigkeit** | Keine (funktioniert immer) | Benötigt aktiven Server des Anbieters |
| **Datenschutz** | Maximal (kein Tracking) | Scans werden auf Servern protokolliert |
| **Kosten** | **100% Kostenlos** | Meist monatliches Abonnement nötig |
| **Bester Einsatz** | Visitenkarten, Speisekarten, Produktverpackungen | Werbekampagnen, A/B-Tests, zeitlich befristete Aktionen |

## Was ist ein statischer QR-Code?

Ein statischer QR-Code codiert Ihre Informationen (z. B. Website-URL, vCard-Kontaktdaten, WLAN-Zugang) **direkt in die Punkte des Musters**. Nach der Erstellung ist der Inhalt untrennbar mit dem Bild verbunden.

### Vorteile von statischen QR-Codes
- **Dauerhafte Gültigkeit**: Der Code verfällt nie.
- **Vollständige Unabhängigkeit**: Selbst wenn der Generator-Dienst nicht mehr existiert, scannt der Code wie am ersten Tag.
- **Perfekter Datenschutz**: Keine Datenspeicherung oder Profilbildung von Nutzern.
- **Keine Folgekosten**: Keine monatlichen Gebühren.

### Nachteile
- **Nicht änderbar**: Ändert sich die verlinkte Website, muss ein neuer Code gedruckt werden.
- **Keine Scan-Zahlen**: Es gibt keine Aufzeichnung über die Anzahl der Scans.

---

## Was ist ein dynamischer QR-Code?

Ein dynamischer QR-Code codiert eine **Kurz-URL** (z. B. `qr.anbieter.de/xyz123`), die den Scanner auf die eigentliche Zieladresse weiterleitet.

### Vorteile
- **Änderbare Zieladresse**: Die Ziel-URL kann im Dashboard des Anbieters geändert werden, ohne neue Plakate oder Flyer drucken zu müssen.
- **Analytics & Statistiken**: Übersicht über Scan-Uhrzeiten, Endgeräte und Länder.

### Nachteile
- **Gefahr von Ausfällen**: Geht der Anbieter offline oder wird das Abo gekündigt, laufen alle gedruckten QR-Codes ins Leere.
- **Datenschutzbedenken**: Jeder Scanvorgang wird mit Standort- und Gerätedaten auf Drittservern gespeichert.

---

## Entscheidungs-Leitfaden: Was sollten Sie wählen?

### Wählen Sie Statisch, wenn:
- Die Ziel-URL dauerhaft stabil ist.
- Sie keine monatlichen Kosten für Abonnements tragen möchten.
- Datenschutz und Ausfallsicherheit oberste Priorität haben.
- Sie Visitenkarten, Speisekarten, Schilder oder dauerhafte Verpackungen bedrucken.

### Wählen Sie Dynamisch, wenn:
- Sie eine kurzfristige Marketingkampagne mit wöchentlich wechselnden Angeboten planen.
- Sie detaillierte Klickstatistiken für Werbebudgets auswerten müssen.
